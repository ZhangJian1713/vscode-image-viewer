# Image Viewer

[English](./README.md) | **中文**

在 **VS Code 和 Cursor** 中查看单张图片，或以图库形式浏览文件夹。通过缩放、拖动、旋转、翻转和导航小地图检查细节，通过缩略图、搜索、排序和筛选查找项目素材。

## 快速开始

| 使用场景 | 操作 |
| --- | --- |
| 打开一张图片 | 在 Explorer（资源管理器）中右键图片 → **Open With...** / **Reopen Editor With...** → **Image Viewer** |
| 设为默认图片查看器 | 打开命令面板（`Ctrl+Shift+P` / `⌘⇧P`）→ **Image Viewer: Use as Default Image Editor** |
| 浏览工作区图片 | 打开文件夹或工作区 → 从命令面板运行 **View Images 🌄** |
| 浏览指定文件夹 | 在 Explorer 中右键文件夹 → **View Images 🌄**，包含其子文件夹 |

## 单图查看器

直接在编辑器标签页中以全屏预览方式打开图片，控件在空闲时自动淡出。

- **缩放：** 使用鼠标滚轮、工具栏按钮，或输入百分比；按 **Space** 或单击主图，在 Fit → Detail → 100% 间自适应循环（中间档收益不明显时为两档，小图使用 Fit/100% → 200%）；放大后拖动可平移；高档预设支持 250%、300%、400%、600% 和 800%。
- **查看细节：** 放大后拖动图片，或通过导航小地图移动查看位置。
- **旋转与翻转：** 向左或向右旋转，水平或垂直翻转；这些显示变换不会修改图片文件。
- **切换图片：** 使用工具栏或侧边箭头查看同目录中的其他图片，顺序跟随 Explorer 的排序设置，包括倒序。
- **键盘操作：** 使用键盘缩放、切换缩放模式、旋转和切换图片。

单图编辑器是只读的。它只列出所打开图片直接所在目录中的图片，不扫描子目录，也不加载图库界面。查看时直接使用原图，不生成缩略图；工作区外的图片也可以打开。

### 设为默认查看器

运行 **Image Viewer: Use as Default Image Editor**，即可默认使用本查看器打开受支持的图片文件。安装或升级扩展不会自动更改默认编辑器。

要移除这些关联，运行 **Image Viewer: Restore VS Code's Default Image Editor**。此后由 VS Code 按正常规则选择编辑器；该命令不会恢复被设置命令覆盖的其他自定义关联。

两个命令都会修改全局 User 设置中的 `workbench.editorAssociations`，工作区和工作区文件夹设置可以覆盖它。恢复命令只移除仍指向 Image Viewer 的受支持图片关联，保留无关或后来改过的关联。如需在卸载时清理这些全局关联，请先运行恢复命令。

## 工作区图库

从左侧 Folders 目录树选择文件夹，在右侧连续的缩略图墙中浏览；点击缩略图打开大图预览。

- **Folders 目录树：** 显示直属或含子目录的图片数量；支持目录搜索、展开/折叠、收起侧栏和拖动调整宽度；从 Folders 菜单切换 **Include subfolders**（包含子目录）；Find folder 右侧的筛选按钮可展开目录扫描规则。右键目录可定位、复制路径、展开/折叠子树，或排除扫描。
- **Fill / Grid / List：** Fill 将缩略图裁切填满方格；Grid 显示完整图片；List 补充路径、大小、原图尺寸和修改时间。底栏缩略图滑动条向右增大图片，实时显示像素；Fill/Grid 支持 1～20 列。
- **紧凑模式：** Fill/Grid 去除间距与常驻文字，List 减小留白；图片菜单仍可使用。
- **滚动位置：** 拖动图片墙滚动条时显示当前屏幕涉及的目录，并在 Folders 树中展开、定位和高亮，不改变当前选中目录；滚轮滚动不触发此指示。
- **大图库：** 图片墙和目录树均采用虚拟滚动，只挂载视口附近的内容。缩略图请求优先处理可见图片，限制并发，并淘汰超出预算的闲置结果。
- **搜索、筛选与排序：** 按文件名/路径搜索，按类型筛选，切换是否包含子目录。默认先按文件夹、再按组内名称排序；名称、修改时间、大小和格式均支持文件夹优先或全局排序。大图切换顺序跟随当前结果；滚动条目录提示和树高亮仅在文件夹优先模式启用。
- **图片菜单：** 定位图片、浏览所在目录、复制路径/文件名/Base64，或经确认后 **Move to Trash**（移入系统回收站）。
- **设置与反馈：** 右下角齿轮打开设置，可调整文件大小显示方式，并查看 Issue 和邮件反馈入口；主题和背景继续使用图库上的控件。
- **外观与目录标签页：** Follow 继承当前编辑器配色；手动 Light / Dark 使用预存的 VS Code Light 2026 / Dark 2026 配色。图片背景依次提供无背景（无底色和边界）、棋盘纹与纯色；支持通过 Explorer 为不同目录打开独立图库标签页。

### 目录规则

目录搜索和扫描筛选可以同时使用。展开 **Find folder** 右侧的筛选按钮，每行输入一条项目相对目录规则，按 Enter 或 **Apply** 应用；Shift+Enter 换行。收起输入区后，已应用的规则继续生效。

| 规则 | 含义 |
| --- | --- |
| `assets` 或 `assets/**` | assets 及其整个目录树 |
| `assets/{photos,icons}/**` | 两个目录及其子树 |
| `**/test-*` | 任意层级中匹配的目录及其子树 |
| `**/{dist,build}` | 任意层级的 dist/build 目录及其子树 |

include 与 exclude 组合使用，exclude 优先。include 留空表示扫描当前入口的整个范围；Explorer 文件夹入口会与 include 取交集。规则采用 Glob（通配符路径匹配），匹配的是目录；图片格式仍由 **Types** 筛选。错误规则会提示且不会应用。

## 图片格式

可识别的文件扩展名：`SVG`、`PNG`、`JPEG`、`JPG`、`ICO`、`GIF`、`WebP`、`BMP`、`TIF`、`TIFF`、`APNG`、`AVIF`。

实际显示能力取决于 VS Code 或 Cursor 的内嵌浏览器；识别扩展名不代表能显示该格式的所有编码。

## 磁盘缓存

VS Code 和 Cursor 可能缓存 WebView（内嵌浏览器视图）加载过的完整图片副本。Image Viewer 会在首屏渲染后、浏览器获得空闲时间片时后台清理旧图片资源缓存。使用过程中会回收不再被打开的面板使用的资源，并为图片切换保留短暂宽限期。

图库与单图编辑器使用独立的缓存作用域。升级后分别打开两种查看器，即可清理各自能访问到的历史缓存。同一作用域内最后一个面板关闭时会尝试清空缓存；崩溃或强制退出后的残留，会在宿主复用该作用域、再次打开查看器时清理。图库的缩略图磁盘缓存与这些资源缓存相互独立。它在打开后及每两分钟检查一次：超过 500 MiB 或 25,000 个文件时，淘汰旧条目直到降至两个上限的 85%。这些是后台软上限，缩略图生成高峰中可能短暂超限。

需要立即清理图库缓存时，运行 **Image Viewer: Clean Gallery WebView Image Cache**；此命令不清理单图编辑器缓存。宿主遗留且已不可达的旧缓存作用域无法由扩展清理，可能需要退出 VS Code 或 Cursor 后手动处理。

## 开发预览

运行 `yarn ui-dev`，然后打开 `http://127.0.0.1:5000/?mock=1`。添加 `&count=100000&folders=1000` 可测试大图库。Mock 使用合成 SVG 和独立浏览器配置，文件菜单操作不会影响真实文件，仅开发模式的浏览器构建可启用。真实工作区图片和宿主交互请通过 F5 → **Run Extension** 验证。
